# Сериализация двусвязного списка с произвольными ссылками

## Описание задачи

Реализация сериализации и десериализации двусвязного списка `ListNode` с произвольными указателями.

## Структура данных

```cpp
struct ListNode {
    ListNode* prev = nullptr;  // указатель на предыдущий элемент или nullptr
    ListNode* next = nullptr;  // указатель на следующий элемент или nullptr
    ListNode* rand = nullptr;  // указатель на произвольный элемент списка или nullptr
    std::string data;          // произвольные пользовательские данные
};
```

**Важно:** Структуру `ListNode` модифицировать нельзя.

## Требования

Необходимо реализовать:

1. Чтение текстового описания списка из файла `inlet.in`
2. Построение связанного списка `ListNode* head` по этим данным
3. Сериализацию списка в бинарный файл `outlet.out`
4. Десериализацию списка из бинарного файла

## Формат входного файла (inlet.in)

Простой текстовый формат. Каждая строка описывает один узел:

```
<data>;<rand_index>
```

Где:
- `<data>` — строка (могут быть пробелы, спецсимволы, кодировка UTF-8)
- `<rand_index>` — индекс узла, на который указывает `rand`, либо `-1`, если `rand == nullptr`

### Пример входного файла

```
apple;2
banana;-1
carrot;1
```

Этот список означает:
- Узел 0: `"apple"` → rand указывает на узел 2
- Узел 1: `"banana"` → rand = nullptr
- Узел 2: `"carrot"` → rand указывает на узел 1

## Формат выходного файла (outlet.out)

Бинарный файл, содержащий сериализованное представление двусвязного списка.

### Структура бинарного файла

1. Количество узлов (int)
2. Для каждого узла:
   - Индекс rand (int, -1 если nullptr)
   - Длина строки data (int)
   - Строка data (без завершающего нуля)

## Ограничения

- Максимальное число узлов: 10⁶
- Длина `data` может быть до 1000 символов
- Поддержка UTF-8 кодировки

## Компиляция и запуск

```bash
g++ -std=c++17 task.cpp -o a.out
./a.out
```

## Реализованные методы

### `ListNode* readfile(const std::string& filename)`
Читает текстовый файл и строит двусвязный список.

### `void serialize(ListNode* head, const std::string& filename)`
Сериализует список в бинарный файл.

### `ListNode* deserialize(const std::string& filename)`
Десериализует список из бинарного файла.

### `void printList(ListNode* head)`
Выводит список в читаемом формате для отладки.

### `void freeList(ListNode* head)`
Освобождает память, занятую списком.

## Особенности реализации

- Используется `std::unordered_map` для сопоставления указателей с индексами
- Бинарная сериализация обеспечивает компактное хранение
- Корректная обработка UTF-8 строк
- Проверка корректности индексов при восстановлении `rand` указателей
